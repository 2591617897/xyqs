## 踩过的坑

1. **`SERVER__PORT=62331` 是 WorkBuddy 自己注入的环境变量**，被 Spring Boot 松散绑定劫持了 `server.port` → 启动报 `Port 62331 was already in use`。
   解决：`unset SERVER__PORT` + `-Dspring-boot.run.arguments=--server.port=8105` 显式覆盖。

2. **setData 后 `repliesShown` 与 `replies` 是两棵独立的树**。只改 `repliesShown` 的点赞态，用户收起/展开回复时（`toggleReplies` 用 `replies` 重建）点赞态会退回旧值。
   解决：`toggleCommentLike` 同时 patch 两条路径；`toggleReplies` 重建时从 `repliesShown` 回填 `liked`/`likeCount`。
