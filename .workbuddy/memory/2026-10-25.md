## 「头像更新不生效」= 上传成功但 /uploads/ 404（2026-10-25 02:20）
- 现场：库 `t_user.avatar` 已是 `https://campus-api.trkcwl.com/uploads/2026/10/880a1503....jpeg`，
  服务器文件管理器里文件也在（`112.54.138.12:/mnt/ssd/web/campus-api.trkcwl.com/uploads/2026/10/`，4.41KB），
  但 `curl https://campus-api.trkcwl.com/uploads/2026/10/880a1503....jpeg`
  → **HTTP 200 + `{"code":404,"msg":"资源不存在"}`**（Spring 的 JSON，不是图片）。
  `<image>` 拿到 JSON 解码失败 → 显示为空/灰块，所以「头像没变」。
- 结论：**写入了 A 目录、静态资源却从 B 目录读**。`UploadController` 与 `WebConfig` 用的是同一个
  `campus.upload.dir`，同进程内不可能不一致 → 只可能是 ① 进程工作目录与预期不同（`./uploads` 相对路径），
  或 ② **Nacos 里残留多个 campus-user 实例**，上传打到一个实例、读取被负载均衡到另一个。
- 代码加固（`campus-user`）：
  - `WebConfig` 启动时校验目录：不存在 → warn；不可读 → error（并提示 /uploads 会 404），
    同时仍打印 `[upload] 静态资源映射 /uploads/** -> file:/...`，**这行是定位这类问题的关键**
  - `UploadController` 落盘后校验 `target.isFile() && length>0`，失败直接抛「图片保存失败」并打绝对路径
- 交付建议（已写进 nginx 模板与 README）：**`/uploads/` 交给 Nginx alias 直出**
  `alias /mnt/ssd/web/campus-api.trkcwl.com/uploads/;`（末尾斜杠必须），
  上传目录与读取路径统一由 Nginx 决定，彻底绕开工作目录/Nacos 多实例问题，且更快。
  同时 `UPLOAD_DIR` 必须用绝对路径。
- 校验：`mvn -pl campus-user compile` 通过。线上仍需用户改 Nginx 或排查 Nacos 实例后重启。

## 修「选学校引导弹层上下滑不动」
- 现象：`components/school-onboard` 列表 24 所学校时滑不动，内容画到「暂不选择」上面
- 根因（与 IP 定位改动无关，只是学校变多才暴露）：`.ob-sheet` 用的是 `max-height: 86vh`，
  高度是内容驱动，里面 `flex:1; min-height:0` 的 `<scroll-view>` 拿到的是内容高度 →
  既不滚动也不裁剪。对比 `pages/user/verify` 的 `.sheet` 是 **定高 `height:76vh`**，所以那边一直正常
- 修法：`.ob-sheet` 改 `height: 78vh`（+ 保留 flex 列 + `.ob-list` 的 `flex:1/min-height:0/overflow:hidden`）
- 顺带：两处 `wx:for` 外层从 `<view>` 换成 `<block>`（不生成额外节点）
- 结论记进 MEMORY 布局铁律：**父容器只给 max-height + 子 scroll-view flex:1 = 不滚动**；
  要么弹层定高，要么把 max-height 加在 scroll-view 自己身上

## 合规咨询：这类小程序上线要什么资质（结论备忘，非代码改动）
- 主体：**必须企业/公司**。个人主体不能做 ICP 备案、开不了社交/UGC 类目（有上线 1 天被永久封的真实案例）
- 三件基础：营业执照（经营范围含「第二类增值电信业务」更好）→ 微信认证 300/年 → **小程序 ICP 备案**（2023-09-01 起强制，免费，5–20 工作日）
- 类目资质：
  - 发帖/评论/私信/表白墙 = 社交-社区/论坛 → 微信侧通常要《增值电信业务经营许可证》B25（ICP 证），不是「ICP 备案」就够
  - 二手撮合若做在线下单+支付+平台结算 → 再加 EDI（B21）；当前项目**无 wx.requestPayment**，纯信息展示+线下交易，可不办 EDI
  - 校园公告若转载时政新闻 → 要《互联网新闻信息服务许可证》；只发本校公告别涉时政
- ICP/EDI 硬门槛：纯内资、注册资本≥100 万、3 人社保、域名已备案、服务器在大陆、建议等保二级
- ⚠️ 最高风险点：**微信有「匿名发布属于尚未开放类目」的驳回/封号先例**。现有 `pages/wall/*` 匿名表白墙需打「前台匿名 + 后台实名可追溯」+ 协议里写明（`legal/agreement.wxml` 4.3 已有这句）

- 校园特有：学籍认证收学生证/学号/实名 = 敏感个人信息，需单独同意+最小必要；建议与学校信息化部门签数据授权
- 后续若加「资助中心」模块：只做信息展示与申请指引，别碰助学贷款撮合（金融类目禁区）
