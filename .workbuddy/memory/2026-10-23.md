## 校园趣事项目从零搭建（QQ 小程序 + Spring Cloud 微服务）

**目标需求**：二手商品管理/发布/浏览/联系购买、匿名表白墙、QQ 频道式帖子、注册强制校园身份认证（选学校）、后端 SpringBoot 微服务。

**产出**（均已完成，后端 `mvn compile` 8 模块全绿，前端 JS/JSON 语法校验通过）：

- `backend/`：Spring Boot 3.2.5 + Spring Cloud 2023.0.1 + SCA 2023.0.1.0，多模块 parent
  - campus-common：`R`/`R.Page` 统一返回、`BizException`、`GlobalExceptionHandler`、`JwtService`、`UserContext`、`SecurityAutoConfig`(Header→ThreadLocal)、`MybatisPlusConfig`、`Like`+`LikeMapper`、`UserClient`(Feign)
  - campus-gateway :8080：`AuthGlobalFilter` 白名单 + JWT 校验 + 清除/注入 `X-User-Id`/`X-School-Id`/`X-Verify-Status`，StripPrefix=1
  - campus-auth :8101（code2Session + JWT + /schools）、campus-user :8102（认证/资料/内部接口）、campus-goods :8103、campus-wall :8104、campus-post :8105
  - 雪花 ID、逻辑状态字段、`t_like` 通用互动表被三服务共用
- `miniprogram/`：10 个页面（发现/二手列表·详情·发布/表白墙/频道列表·详情·发帖/我的/认证），`utils/{config,request,auth,util}.js`，兼容 `qq`/`wx` 宿主 API
- `backend/sql/{schema,data}.sql`、`docker-compose.yml`(MySQL+Redis+Nacos)、`README.md`、`docs/{architecture,api}.md`

**关键决策**
- 网关统一鉴权，业务服务只读 Header，业务代码用 `UserContext`
- 作者昵称/头像做读模型快照（`seller_name`/`author_name`），列表页免 Feign N+1
- 表白墙 `user_id` 只入库（`@JsonIgnore`），对外匿名昵称由 `userId+postId` 派生，避免跨帖串联
- 认证通过后重签 token 返回给前端替换（token 内嵌 verifyStatus）
- 本地无 AppID 时 `QQ_MOCK=true` + `DEV_OPENID` 固定 openid，保证重复登录同一用户

**已知待补**：图片仍存本地临时路径（需对象存储）、审核台/内容安全、Redis 计数、`t_like` 拆库；本机没有 Docker，未做运行时联调。

**用户偏好**：中文沟通；偏好微服务架构、完整可交付代码而非片段。

## 追加：修复小程序白屏（usingComponents undefined）

**现象**：QQ 开发者工具模拟器只有导航栏 + tabBar，页面内容空白；Console 报
`Cannot read properties of undefined (reading "usingComponents")`（WAWebview.js:261）。

**根因**：10 个页面里只有 4 个有 `.json`，缺 6 个（goods/detail、goods/publish、post/detail、
post/publish、user/index、user/verify）。框架读不到页面配置对象 → pageConfig undefined → 白屏。
**这是静态语法检查发现不了的，只有结构校验能查。**

**修复**
- 补齐 10 个页面 json，全部显式写 `"usingComponents": {}`
- `app.json` 移除 `"style": "v2"`（QQ 不支持，属微信扩展字段）；不加全局 usingComponents（老基础库兼容性）
- 新增 `scripts/check-miniprogram.js`：校验页面 js/wxml/json 齐全、json 可解析且含 usingComponents、
  tabBar 页面已声明、页面 js 有 Page()、sitemap 存在、BOM 检查

**环境事实**：QQ 开发者工具已回写 `project.config.json`（加了 `qqappid: 1108100302`、`libVersion: 1.10.0`）。
基础库 1.10.0 偏老，对 CSS `gap`/`env()`、`wx:elif` 支持有限，真机可能布局异常。

**教训**：小程序页面 json 不是可选项（尤其 QQ），新建页面必须同时产出 4 个文件；加结构校验脚本兜底。
