## 修复：帖子/表白墙举报提交不了（用户报「没有权限」）

现象：点提交举报 → Console `TypeError: http is not a function`，旁边还挂着一个 401。
真因在前端，跟后端权限无关。

### 根因 1：`http` 不是函数
`miniprogram/utils/request.js` 的 `module.exports` 是**对象** `{ request, get, post, put, del }`，
但 `pages/report/report.js` 写成了 `http({ url, method, data })` → 同步抛 TypeError，请求根本没发出去。
全项目只有这一处这么写（其余 20+ 处都是 `http.get/post(...)`），所以只有举报挂。
修复：改 `http.post('/user/report', data, { loading: '提交中' })`。

### 根因 2：雪花 id 被 Number() 截断（顺手修）
原代码 `targetId: Number(d.targetId)`。19 位雪花 id > `Number.MAX_SAFE_INTEGER`：
`2114021598989209601 → 2114021598989209600`，工单会挂到错误内容上。改成 `String(...)`。

### 根因 3：意见反馈（FEEDBACK）提交必 500
`t_report_ticket.target_id` 建表是 `NOT NULL` 无默认值，而 FEEDBACK 没有举报对象（targetId=null）
→ `Field 'target_id' doesn't have a default value`。
之前从没暴露，因为请求压根没发出去。已放开空约束（MySQL 唯一索引允许多行 NULL，
所以每条反馈各自成单，不会被 `uk_target_reporter` 误合并——已实测两条反馈生成两张工单）。
迁移脚本 `backend/sql/migration-20261027-report-fix.sql`（幂等，需先 `USE guizhou_campus_fun`）。

### 顺带
- 举报是写操作 → 提交前套 `auth.ensureLogin()`，游客先弹登录确认，而不是吃一个裸 401
- `scripts/check-miniprogram.js` 新增断言：扫描 pages/components/utils，
  禁止把 `utils/request` 模块本身当函数调用（**必须先剔注释再匹配**，注释里引用了错误写法）

## 首页 Banner 宽度对齐（同日）

用户反馈「广告轮播图宽度和其他的不一样」。原因：`.banner` 是 `width:100%; margin-top:16rpx`（满屏 750rpx），
而 `.announce` / `.zone-head` / `.hot-card` 统统是左右各 24rpx；`<image>` 上还挂了个行内
`style="width: 723rpx"`（开发者工具自动生成的残留），于是图比卡片窄 20rpx 且右侧留白不对称。

统一为：**左右 24rpx + 圆角 24rpx**，与卡片一致。
⚠️ swiper 默认宽度就是 100%，改成带左右 margin 时必须把 `width` 写 `auto`，
   否则 100% + 48rpx margin 会撑出横向溢出（整页能左右滑）。
行内 `width: 723rpx` 已删除，宽度统一交给 `.banner-img`（100%）。

首页横向节奏速查：内容区 = 750 - 24*2 = **702rpx**，外边距 24rpx、卡片圆角 24rpx。

## 模拟器启动失败：usingComponents 组件路径写成了相对路径（同日）

报错：`pages/goods/detail.json: ["usingComponents"]["promote-sheet"]: "components/promote-sheet/promote-sheet" 未找到组件`
（日志里会列出 pages/goods/components/...、pages/goods/miniprogram_npm/... 等一堆候选路径）

根因：小程序 `usingComponents` 的路径规则 —— **以 `/` 开头 = 相对小程序根目录**，否则 **相对该 json 所在目录**。
`promote-sheet` 实际在 `miniprogram/components/`，但 `pages/{goods,post,wall}/detail.json` 三处都写成了
`components/promote-sheet/promote-sheet` → 被解析成 `pages/xxx/components/...`，三页全挂（工具只报第一个）。

修复：三处统一改成 `/components/promote-sheet/promote-sheet`（与项目其余页面一致：
`pages/index/index.json`、`pages/user/index.json` 等本来就用的 `/components/...`）。

⚠️ 约定：**页面/组件 json 里引用根目录组件，一律写 `/components/xxx/xxx`**，别偷懒省 `/`。
