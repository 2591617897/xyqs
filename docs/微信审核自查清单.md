# 校聚一城 · 微信审核自查清单

> 品牌：**校聚一城**　定位：立足本校，结识同城各校同窗
> 功能：学习答疑 / 树洞闲谈 / 社团招新 / 闲置交换 / 校园趣事 / 校园公告
> 关键红线：**平台没有支付功能，闲置物品禁止线上交易，一律校内当面交付**

## 一、审核最容易卡的三件事（先看这个）

| 风险点 | 微信的判断依据 | 我们的处理 |
| --- | --- | --- |
| 被当成「电商/二手交易平台」 | 页面出现下单、支付、担保、退款、邮寄、收货地址、包邮 | 全站删除「支持邮寄」；发布页固定 `tradeType=1`（校内自提）；详情页主按钮改为「约当面看货」；列表页顶部常驻"不支持线上交易"提示条 |
| 被当成「婚恋交友」 | 名称/文案含表白、恋爱、脱单、送花、交友 | 「匿名表白墙」→「树洞闲谈」；分类「精选表白」→「校园心情」；毕业季 banner 去掉"浪漫 / 喜欢 / 送花"；简介按"校园信息交流"写 |
| 被当成「无资质 UGC 论坛」且缺少内容治理 | 有发帖无审核、无举报、无规范、无隐私政策 | 发帖/发闲置/发树洞全部走 `SecurityGuard`（微信内容安全）；发帖前必须勾选《社区规范》；全站详情页有举报入口；新增社区规范页 |

## 三、微信后台必须配的（代码改不了）

1. **小程序名称**：`校聚一城`（需查重；若被占用，备选「校聚一城校园圈」「校聚一城·同城校园」）
2. **小程序简介**（务必写成信息交流，不要出现交易/买卖/二手市场）：
   > 校聚一城是面向在校学生的校园信息交流平台，提供本校圈子、学习答疑、树洞闲谈、社团招新与闲置信息浏览，平台不提供线上交易与支付功能。
3. **服务类目**：
   - 首选：`社交 - 社区/论坛`（企业主体，部分情况需 ICP 备案）
   - 若审核要求补充：`教育 - 在线教育（信息展示）`
   - **不要**选「电商平台 / 商家自营 / 二手交易」，选了就要求支付与资质
4. **用户隐私保护指引**（`app.json` 已开 `__usePrivacyCheck__: true`）：
   - 声明收集：微信登录标识、昵称头像、相册/相机（上传图片与认证）、学校与学号、设备信息与 IP
   - 用途逐项填写，与《隐私政策》第一章表格一致
   - 声明"不收集精确位置、不收集支付信息、不收集通讯录"
5. **服务器域名**：request / uploadFile / downloadFile 三个都要配（生产 HTTPS + 已备案）
6. **内容安全**：确认已开通 `security.msgSecCheck`、`security.mediaCheckAsync`，并在小程序后台把服务器出口 IP 加进白名单（否则报 40164，会被 fail-open 静默放行）
7. **客服/联系方式**：邮箱 `privacy@trkcwl.com` 必须真实可收信；建议同时挂微信客服
8. **微信学生身份认证**（可选，非必须）：开通后会替代「上传学生证」。
   两个硬性门槛决定了它可能申请不下来：① 服务类目必须在官方白名单（教育/生活服务/工具/电商/餐饮/旅游/文娱等），
   **`社交 - 社区/论坛` 不在名单内**；② 用途必须是「给学生提供优惠活动」，我们是身份校验。
   代码已做成开关（默认关闭，`node scripts/wx-student-plugin.js off`），
   关掉后认证页只剩学生证通道，不影响提审。完整说明见 `docs/微信学生认证接入说明.md`。

## 五、常见驳回理由与对应改法

| 驳回理由 | 对应处理 |
| --- | --- |
| 涉及交易，需补充电商类目/支付资质 | 说明无支付；检查是否还有"下单/购买/邮寄/包邮/担保"字样；`goods` 主按钮已改"约当面看货" |
| 涉及婚恋交友 | 已去"表白"字样；若仍被卡，把「树洞闲谈」分类里的"校园心情"再改为"日常吐槽" |
| UGC 无审核机制 | 提交 `SecurityGuard` 接入说明 + 举报入口截图 + 社区规范页 |
| 存在诱导分享 | 分享按钮走 `open-type="share"`，无"分享得奖励"文案；检查运营公告文案 |
| 收集个人信息未声明 | 补全隐私指引四项；确认首次进入弹隐私授权 |
| 名称含"最/第一/官方"等绝对化用语 | `校聚一城` 不含，安全 |
| 空白页/功能不完整 | 用演示账号走一遍 24 个页面（见下） |
